# 🔐 BIENVENUE DANS L'ESCAPE ROOM GIT

⏰ **Temps limite : 60 minutes**

## VOTRE MISSION

Le développeur principal de TechCorp a disparu mystérieusement. Avant de partir, 
il a caché des indices cruciaux dans ce dépôt Git. Votre équipe doit :

1. Trouver les **6 fragments de code** dispersés dans le dépôt
2. Résoudre les **conflits** pour reconstituer le message final
3. Découvrir le **code de sortie** avant l'effacement définitif du serveur

## ⚙️ RÈGLES DU JEU

- Utilisez **UNIQUEMENT les commandes Git**
- Chaque indice vous guidera vers le suivant
- Le **travail d'équipe** est essentiel !
- Réfléchissez avant d'agir - les commandes ne sont pas données !

## PREMIER INDICE

La structure de ce dépôt cache des secrets. Pour commencer, vous devez comprendre
comment le projet est organisé.
